Why doesn't https://nakabposh.github.io/gspn/context/manpower.json update automatically?
GitHub Pages is a static site. When you edit records in the browser, changes are saved to your browser's local memory. To update the public file https://nakabposh.github.io/gspn/context/manpower.json across production so all devices see the updated Team Leaders and engineers:

Array Schema Reference

branchCode (string): Service center branch code
branchName (string): MSC branch city name
no (number): Serial order in roster
engineerCode (string): Unique engineer employee ID
engineerType (string): Role (In-Home / Carry-In / Workshop)
name (string): Full name of engineer
telNo (string): Contact telephone number
status (string): Active / Leave / Inactive
tlName (string): Assigned Team Leader
trackerName (string): Assigned Operations Tracker
